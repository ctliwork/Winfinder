# WinFinder

**下載安裝：** [WinFinder_x64-setup.exe](https://github.com/ctliwork/winfinder/releases/latest/download/WinFinder_x64-setup.exe)（Windows 10／11，64 位元）
裝好之後有新版本會自動提示，按「更新並重新啟動」即可。

仿 macOS Finder 的 Windows 檔案管理器，重點是直欄檢視（column view）。
後端用 Rust（Tauri 2），介面是 HTML／CSS／JS。

## 架構

| 部分 | 位置 | 說明 |
|---|---|---|
| 介面 | `renderer/` | 所有檢視、Quick Look、選單、鍵盤操作 |
| Rust 後端 | `src-tauri/src/` | 讀目錄、搜尋、檔案操作、縮圖、資料夾監看 |
| Tauri 橋接 | `renderer/bridge-tauri.js` | 把介面的 API 對到 Rust 指令 |
| Electron 外殼 | `main.js`、`preload.js` | 只用於自動化介面測試，不是正式版本 |

Rust 後端各模組：

- `fsops.rs`：列出資料夾（Windows 上大小、時間、隱藏／系統屬性在列目錄時一次取得，不必逐檔查詢）、重新命名、新增資料夾、拷貝／搬移
- `search.rs`：用 jwalk 多執行緒搜尋子資料夾
- `prevhost.rs`：在直欄的預覽欄與預覽窗格嵌入檔案總管的預覽處理常式（IPreviewHandler），在自己的 STA 執行緒上執行
- `places.rs`：側邊欄位置、磁碟代號與名稱、剩餘空間
- `thumb.rs`：Windows 殼層縮圖（圖片、影片、PDF、Office 檔）
- `preview.rs`：解析 Word／PowerPoint／Excel 內容（含 .doc／.xls 舊格式）與壓縮檔清單，給預覽用
- `archive.rs`：ZIP 壓縮與解壓縮；其他格式透過 7-Zip 或 Windows 的 tar.exe
- `recent.rs`：讀取系統的「最近使用的檔案」
- `content.rs`：用 Windows 搜尋索引搜尋檔案內容
- `cloud.rs`：OneDrive 等雲端同步狀態（從列目錄時已取得的檔案屬性判斷）與「一律保留在此裝置」「釋放空間」（Cloud Files API）
- `lib.rs`：Tauri 指令、資料夾監看（notify）、自動更新、視窗（Windows 11 Mica 效果）

## 效能實測

列出 20,000 個檔案的資料夾（Linux 開發環境，5 次取最佳）：

| 後端 | 時間 |
|---|---|
| Rust（`fsops::list`） | 33 ms |
| Node（舊版 Electron 後端） | 749 ms |

Windows 上的差距預期更大（Node 每個檔案都要另外開檔查詢），但還沒在 Windows 實測。
自己測：

```bash
cd src-tauri && cargo run --release --example bench_list -- C:\某個大資料夾
node bench/bench-list.js C:\某個大資料夾
```

## 開發與打包

需要 Node 22 和 Rust（stable）。Windows 上另需 WebView2（Windows 11 內建）。

```bash
npm install
npm run dev      # 開發模式
npm run build    # 產生安裝檔：src-tauri/target/release/bundle/nsis/*.exe
npm test         # Rust 單元測試
```

指定起始資料夾：`WinFinder.exe --dir=D:\Projects`

## 發布新版本與自動更新

發布是手動的：到 GitHub 的 **Actions → Release → Run workflow**（可以填更新說明）。流程會：

1. 在 Windows 上跑 Rust 測試
2. 把版本設成 `0.3.<執行編號>`，每次自動遞增
3. 打包安裝檔，用更新私鑰簽章，發布成 GitHub Release，附上 `latest.json`
4. 另外上傳固定檔名的 `WinFinder_x64-setup.exe`（也上傳一份改名前的 `Finder-for-Windows_x64-setup.exe`，舊連結不會失效），讓上面的下載連結永遠指向最新版

已安裝的 App 啟動後幾秒會讀 `releases/latest/download/latest.json`，有新版就在右下角提示；也可以從「⋯」選單手動「檢查更新…」。下載的更新會用 `tauri.conf.json` 裡的公鑰驗證簽章，對不上就不會安裝。

**一次性設定：** repo 的 Settings → Secrets and variables → Actions 要有 `TAURI_SIGNING_PRIVATE_KEY`（更新簽章私鑰，無密碼）。私鑰不在 repo 裡，請另外備份；遺失後已安裝的版本就收不到更新，只能手動重裝新版。推送程式碼不會自動打包。

## 功能

- 啟動時打開「常用」（同 Windows 檔案總管）：快速存取的釘選資料夾、磁碟機與容量、最近使用的檔案
- 左側導覽樹（同 Files／檔案總管）：首頁、釘選、本機磁碟機，資料夾可逐層展開
- 分頁：Ctrl+T 新分頁、滑鼠中鍵關閉分頁、在資料夾上按中鍵以新分頁打開；拖曳分頁可調整順序；把檔案拖到分頁上會放進那個分頁的資料夾，拖著停一下會切換過去；重開程式會回到上次的所有分頁（像 Finder，可在設定中改）
- 視窗按鈕在右上角（Windows 樣式）
- 四種檢視：圖像、列表、**直欄**（預設）、圖庫；每個資料夾記住自己的檢視方式與排序（可在設定關閉）
- 列表檢視：拖曳標題邊線調整欄寬；在標題上按右鍵可加上「建立日期」「副檔名」欄，或依類型、修改日期、大小分組（圖像檢視也能分組）
- 直欄檢視：點選逐層展開、右側預覽欄（圖片、影片、Word／Excel／PowerPoint、PDF、文字直接預覽）、方向鍵上下選取、左右切換欄位
- 直欄選取跟 Finder 一樣：Ctrl／Shift＋點選多選、Ctrl+A 全選該欄、多選一起拖曳、預覽欄顯示「已選取 N 個項目」、點欄位空白處取消選取、在欄內框選、Alt+P 隱藏預覽欄、選取後停頓再點名稱即重新命名
- 直欄寬度：拖曳欄位右邊線調整（按住 Alt 一次調整全部欄）、按兩下自動符合最長檔名；寬度會依資料夾記住
- 空白鍵 Quick Look：圖片、影片、音訊、PDF、文字／原始碼，開關有縮放動畫
- 預覽窗格（Alt+P，同檔案總管）：選取檔案就在右側顯示預覽和詳細資訊
- 預覽速度：大張相片（1.5 MB 以上）先顯示 Windows 已有的縮圖，完整相片解碼好再換上；看著一個檔案時會先準備好前後兩個檔案的預覽，用方向鍵瀏覽時立即顯示；最近看過的預覽也會記住
- 預覽可放大縮小（直欄檢視右側的預覽、預覽窗格、快速查看）：圖片、影片用滾輪或按兩下縮放、拖曳移動；文件、表格、程式碼用 Ctrl+滾輪；快速查看中可按 Ctrl+= / Ctrl+- / Ctrl+0，滑鼠移到預覽上會出現縮放列
- 預覽格式：Word（標題與內文）、Excel（表格與工作表名稱）、PowerPoint（逐頁）、沒裝 Office 也能看舊格式 .doc（內文與表格）和 .xls（含 .xlsb、.ods，日期與公式結果）、ZIP 內容清單、Markdown、CSV／TSV 表格、程式碼（含行號）、字型（.ttf／.otf／.woff，範例文字與各種大小）；Windows 上其他格式用系統縮圖
- OneDrive 同步狀態：名稱旁顯示與檔案總管相同的圖示（雲朵＝僅在線上提供、綠色勾＝可在此裝置上使用、實心綠勾＝一律在此裝置上提供、箭頭＝正在下載），預覽窗格也會顯示狀態；Finder 風格選單有「一律保留在此裝置」「釋放空間」（Windows 選單本來就有 OneDrive 的這兩項）
- 導覽窗格與 Windows 檔案總管相同：常用、OneDrive、快速存取的釘選資料夾（直接讀取檔案總管的清單，在這裡釘選／取消釘選也會同步到檔案總管）、本機與磁碟機
- 圖示與 Windows 檔案總管相同：應用程式與捷徑用自己的圖示、檔案用系統的類型圖示、資料夾與磁碟機用 Windows 的圖示（含自訂圖示）；大圖示檢視中的相片、影片、文件仍顯示縮圖。可在設定中關閉改回 Finder 風格
- **設定**（Ctrl+, 或「⋯」→ 設定）：啟動位置（上次的所有分頁／常用／上次的位置／指定資料夾）、計算所有大小、新分頁位置、預設檢視、刪除前確認、自動檢查更新、主題（跟隨系統／淺色／深色）、強調色、介面與字體大小（90%～175%，整個視窗一起縮放）、Windows 圖示、列表密度、側邊欄、預覽窗格、隱藏項目、副檔名、資料夾排前面、大小單位（1000／1024）、還原欄寬、重設所有設定、快捷鍵一覽
- 路徑列可直接輸入路徑（點路徑列空白處或 Ctrl+L／Alt+D／F4）；輸入檔案路徑會打開所在資料夾並選取它
- 狀態列與剩餘空間
- 拖放：同磁碟搬移、跨磁碟或按 Ctrl 拷貝；可拖到其他 App、也可從檔案總管拖進來
- Finder 的動態效果：彈簧資料夾（拖著檔案停在資料夾上會閃兩下並自動打開）、快速查看從圖示放大／縮回、圖像檢視改排序或分組時圖示平順移到新位置
- 新增資料夾、新增文字文件、重新命名、製作副本、拷貝／剪下／貼上、丟到資源回收筒
- 右鍵選單與 Windows 相同：直接顯示檔案總管的選單（7-Zip、VS Code、Git 等加入的項目都在），上方加上本程式的功能（在新分頁中打開、快速查看、拷貝路徑、計算大小；空白處有檢視、排序方式、分組依據）；設定中可改回 Finder 風格選單。「內容」視窗（Alt+Enter）
- 剪貼簿與檔案總管互通：這裡拷貝／剪下的檔案可在檔案總管或桌面貼上，反之亦然
- 復原（Ctrl+Z）：重新命名、批次重新命名、搬移、拷貝、新增、壓縮／解壓縮、丟到資源回收筒（從資源回收筒還原）
- 貼上遇到同名項目時詢問：取代（資料夾會合併）、略過、保留兩者；較久的拷貝顯示進度並可取消
- 批次重新命名（多選後按 F2）：尋找與取代（可用正規表示式）或名稱加編號，套用前先預覽並檢查重複與無效名稱
- 壓縮成 ZIP、解壓縮到同名資料夾：ZIP 內建；7z、RAR、TAR、GZ、ISO、CAB 等用 7-Zip（有安裝時，也可以預覽內容清單），沒有 7-Zip 時用 Windows 內建的 tar 解壓縮
- 直欄的預覽欄與右側預覽窗格跟檔案總管的預覽窗格一樣：Office（含 .doc／.xls／.ppt 舊格式）等用 Windows 註冊的預覽處理常式顯示（有裝 Office 才有 Office 預覽）；圖片、影片、音樂、PDF、文字、程式碼與 CSV 用內建預覽（立即顯示，Edge 的 PDF 預覽和 PowerToys 的程式碼預覽啟動都要一秒多），沒有預覽處理常式的類型也用內建預覽；設定 → 外觀可關閉。預覽處理常式啟動後會保留重複使用（跟檔案總管一樣），打開資料夾時也會先在背景啟動最常見的幾種，所以切換檔案時不必每次重新啟動
- 圖庫檢視上方與直欄的預覽欄都顯示完整預覽（PDF、Word、Excel、PowerPoint、文字檔、圖片、影片），文件與 PDF 佔大部分高度可直接閱讀
- 計算資料夾大小（右鍵選單或預覽窗格），結果會顯示在列表的大小欄；開啟「計算所有大小」（列表標題右鍵、⋯ 選單或設定）後，列表會在背景算出每個資料夾的大小，可依大小排序
- 在終端機中開啟（Windows Terminal，沒有安裝時用 PowerShell）
- 目前資料夾即時篩選、含子資料夾的搜尋；可再依類型、大小、修改日期篩選；「檔案內容」用 Windows 搜尋索引（檔案總管搜尋用的同一個）找出內容含有這些字的文件，只搜有建立索引的位置；有安裝 Everything（含 es.exe）時可搜尋整台電腦
- 指向資料夾的捷徑（.lnk）直接在本程式中打開（像 Finder 的替身）；右鍵「顯示原始項目」跳到目標所在位置並選取
- 智慧型資料夾（Finder 的「儲存的搜尋」）：搜尋列右邊按「儲存」，把搜尋字、範圍與篩選條件存到側邊欄，點一下就重新搜尋；打開後修改條件再按「儲存」會更新；右鍵可重新命名或移除
- 框選、Shift／Ctrl 多選、打字跳選、資料夾變動自動更新
- 大資料夾（1000 個項目以上）只畫畫面上看得到的列：列表、圖像、直欄與圖庫在上萬個檔案時打開、捲動、全選都不會卡（2 萬個檔案：打開約 0.1 秒，全選從約 3 秒變成 0.06 秒）
- 深色／淺色模式、8 種強調色；視窗完全不透明，啟動時不會閃白
- 常駐背景：按 × 只把視窗藏起來，程式留在通知區域（系統匣），再打開是瞬間；點通知區域的圖示打開，右鍵有「新分頁」「結束」。再次從開始功能表或捷徑啟動會叫出已在執行的視窗（指定的資料夾開在新分頁），不會多開一份。設定 → 一般可關閉，也可開啟「登入 Windows 時在背景啟動」，開機後第一次打開也不用等

## 快捷鍵

| 按鍵 | 動作 |
|---|---|
| Ctrl+T | 新分頁 |
| 滑鼠中鍵（分頁上） | 關閉分頁 |
| 滑鼠中鍵（資料夾上） | 以新分頁打開 |
| Ctrl+W | 關閉分頁 |
| Ctrl+Tab / Ctrl+Shift+Tab | 下一個／上一個分頁 |
| Ctrl+1/2/3/4 | 圖像／列表／直欄／圖庫 |
| Alt+P | 預覽窗格 |
| 空白鍵 | Quick Look |
| Enter、Ctrl+↓ | 打開 |
| F2 | 重新命名 |
| Delete | 丟到資源回收筒 |
| Alt+← / Alt+→ / Alt+↑ | 上一頁／下一頁／上層 |
| Ctrl+Shift+N | 新增資料夾 |
| Ctrl+Alt+N | 新增文字文件 |
| Ctrl+L、Alt+D、F4 | 輸入路徑 |
| F2（多選） | 批次重新命名 |
| Ctrl+, | 設定 |
| Ctrl+Z | 復原 |
| Alt+Enter | 內容 |
| Shift+F10、Shift+右鍵 | Windows 原生右鍵選單 |
| Ctrl+Shift+. | 顯示隱藏項目 |
| Ctrl+F | 搜尋 |
| Ctrl+= / Ctrl+- | 圖像大小 |
