## 本版改動

- 直欄預覽欄及右側預覽窗格優先使用註冊的 Windows 預覽處理程式。
- 修正快速切檔、關閉後舊預覽回來、舊指令卸載新預覽及缺少處理程式結果持續快取。
- 原生預覽失敗明確標示替代內容，保留錯誤階段與 HRESULT。
- 直欄右鍵及 Ctrl 多選資料夾不再意外開啟它。
