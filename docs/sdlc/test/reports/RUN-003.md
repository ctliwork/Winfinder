## 取捨與影響

選擇在 await 後檢查請求與編輯生命週期，重用既有 working、track、undo 和 refresh 延後機制。全面序列化所有操作雖可減少競態，但會讓慢速資料夾讀取阻塞鍵盤及搜尋，且修改範圍過大。資料寫入仍由既有原生檔案 API 負責；無新增依賴或設定。

## 驗證限制

- 原生 Windows popup 的「新增資料夾」實際點選，以及微軟注音／拼音候選確認，需人工確認。WebView2 測試以原生指令回傳或組字事件注入驗證 renderer 路由，不宣稱已測實際 IME。
- 本次檢查不等同已證明所有環境、網路磁碟或所有操作時序沒有缺陷。

## 自動化測試本身的修正

CHG-006：檔案存在不等於複製完成，ST-008 改等 transfer Promise 回傳才讀檔；路徑已是目標時不再用同一個舊 breadcrumb 當新導覽完成訊號；空目錄以 empty placeholder 判定完成；祖先背景點選採 Playwright 元素定位及穩定性檢查。保留原本的內容、路徑、焦點與復原斷言，未以固定延遲或跳過斷言取得通過。
